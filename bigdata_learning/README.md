## 🚀 快速开始（Windows）

1. 安装 **Python 3.8 或更高版本**（https://www.python.org/downloads/ ，安装时勾选 *Add Python to PATH*）。
2. 双击 **`start.bat`**。
3. 浏览器自动打开 `http://127.0.0.1:8321`，开始学习！

> 无需安装任何第三方依赖（纯 Python 标准库），可完全离线使用。学习进度自动保存在 `data/learning.db`。

## 🎮 闯关机制说明

- **自由探索**：所有章节无需解锁，侧边栏目录可展开查看每章进度（绿色实心圆 ● = 通关，空心圆 ○ = 未完成）。
- **运行与判题分离**：代码题先点「▶ 运行」查看自己的输出/查询结果，确认后再「提交判题」。
- **判题方式**：
  - SQL 题：你的 SQL 会在内存 SQLite 中执行，与标准结果集比对（行集合 + 行数），差异逐行反馈，并同时展示「你的结果表」与「标准结果表」。
  - Python 题：你的代码在本机 Python 子进程中运行（15 秒超时），输出与期望输出逐行对照；报错会显示完整错误信息。
- **通关流程**：本章全部任务通过后，自动出现「🎉 下一章」大按钮；每章底部有速记卡（常见问题 + 重点词汇）用于巩固。
- **得分规则**：首次答对满分；每多错一次得分递减（100%→60%→30%→15%→5%）；动手实践 +40XP；每日打卡 +10XP。
- **连击**：连续答对产生连击提示；答错清零。
- **徽章**：共 11 枚（首战告捷、SQL 小能手、编程家、动手达人、连续打卡、阶段王者、毕业等）。
- **面试宝典**：侧边栏「🎤 面试宝典」，按 13 个阶段分类的高频面试题，答案结构化可背诵，支持自测模式与已复习进度记录（本地保存）。

## ✏️ 扩展 / 自定义内容

所有课程内容都是 JSON 文件，想加章节、加题目直接编辑 `content/` 下的文件即可：

1. 先读 `content/_SCHEMA.md` 了解字段规范与 6 种题型的写法（含速记卡 qa/glossary 格式）。
2. 用补丁工具追加内容（不用手改大 JSON）：`python tools/content_tools.py apply 补丁.json`，补丁格式见 _SCHEMA.md 第七节。
3. 运行 `python tools/validate_content.py` 校验内容（会预执行 SQL 期望语句和 Python 参考答案）。
4. 重启 `start.bat` 生效。

## ❓ 常见问题

- **双击 start.bat 提示找不到 Python**：去 python.org 安装并勾选 Add Python to PATH，然后重新双击。
- **端口被占用**：程序会自动尝试 8321~8330 端口，以窗口显示的地址为准。
- **浏览器没自动打开**：手动访问 http://127.0.0.1:8321 即可。
- **想清空进度重新学**：首页底部「⚠ 重置全部进度」。
- **SQL/Python 判题环境的限制**：SQL 题使用 SQLite 兼容语法（题目中有说明）；Python 题只能使用标准库（不依赖 pyspark 等，用纯 Python 模拟分布式概念），这是为了让没有集群环境的学习者也能动手练习。
